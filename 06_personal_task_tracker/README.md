# 06 Personal Task Tracker

Консольный менеджер задач на Python.

Программа позволяет добавлять задачи, просматривать список, отмечать задачи выполненными, удалять и редактировать их, смотреть статистику, а также сохранять и загружать задачи из JSON-файла.

## Возможности

* добавление задач;
* проверка пустого названия задачи;
* нормализация лишних пробелов в названии;
* просмотр списка задач;
* отображение статуса задачи:

  * `[ ]` — не выполнена;
  * `[x]` — выполнена;
* отметка задачи как выполненной;
* удаление задачи по номеру;
* изменение названия задачи;
* подсчёт статистики:

  * всего задач;
  * выполнено;
  * не выполнено;
* сохранение задач в `tasks.json`;
* загрузка задач из `tasks.json`;
* автоматическая загрузка задач при запуске;
* подтверждение сохранения перед выходом;
* обработка ошибок при загрузке:

  * файл не найден;
  * JSON-файл повреждён;
  * данные имеют неверный формат.

## Структура задачи

Каждая задача хранится как словарь:

```python
{
    "title": "Купить хлеб",
    "done": False
}
```

Все задачи хранятся в списке:

```python
[
    {"title": "Купить хлеб", "done": False},
    {"title": "Позаниматься Python", "done": True}
]
```

## Сохранение данных

Задачи сохраняются в файл:

```text
tasks.json
```

Файл `tasks.json` не добавляется в Git, потому что это пользовательские данные.

## Как запустить

Перейти в папку проекта:

```bash
cd 06_personal_task_tracker
```

Запустить программу:

```bash
python main.py
```
