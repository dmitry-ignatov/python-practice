# Personal Task Tracker

Консольный менеджер задач с хранением данных в JSON.

Задачи можно добавлять, редактировать, удалять и отмечать выполненными. Программа показывает статистику и умеет автоматически загружать сохранённые данные при запуске.

## Что предусмотрено

- сохранение и загрузка через `json.dump()` / `json.load()`;
- проверка структуры загруженных данных;
- обработка отсутствующего и повреждённого JSON;
- подтверждение сохранения перед выходом.

## Запуск

`python main.py`
