# 16 Task API SQLite

Учебный REST API для управления задачами на FastAPI с хранением данных в SQLite.

Проект продолжает `15_task_api`: структура API и CRUD-операции остаются знакомыми, но вместо обычного Python-списка задачи теперь сохраняются в настоящей базе данных. Основная цель проекта — соединить уже изученные FastAPI и SQLite через стандартный модуль `sqlite3`, не переходя пока к ORM и SQLAlchemy.

## Возможности

API позволяет:

* получить список всех задач;
* получить задачу по её `id`;
* создать новую задачу;
* изменить название существующей задачи;
* удалить задачу;
* вернуть `404 Not Found`, если запрошенной задачи нет;
* сохранять задачи между перезапусками приложения в SQLite;
* автоматически создавать таблицу `tasks` при запуске приложения;
* корректно открывать и закрывать соединения с базой данных;
* автоматически проверять основное поведение API через `pytest` и `TestClient`;
* запускать тесты на отдельной временной SQLite-базе, не затрагивая обычный `tasks.db`.

## Endpoints

### `GET /tasks`

Возвращает список всех задач.

Пример:

```json
[
  {
    "id": 1,
    "title": "Купить хлеб"
  },
  {
    "id": 2,
    "title": "Выучить FastAPI"
  }
]
```

Если задач нет, возвращается пустой список:

```json
[]
```

### `GET /tasks/{task_id}`

Возвращает одну задачу по её `id`.

Если задачи нет, API отвечает кодом `404`:

```json
{
  "detail": "Task not found"
}
```

### `POST /tasks`

Создаёт новую задачу и сохраняет её в SQLite.

Тело запроса:

```json
{
  "title": "Новая задача"
}
```

Пример ответа:

```json
{
  "id": 3,
  "title": "Новая задача"
}
```

При успешном создании используется статус `201 Created`.

Для получения `id`, который SQLite присвоила новой записи, используется `cursor.lastrowid`.

### `PATCH /tasks/{task_id}`

Изменяет название существующей задачи.

Тело запроса:

```json
{
  "title": "Новое название"
}
```

Если задача не найдена, API отвечает `404 Not Found`.

### `DELETE /tasks/{task_id}`

Удаляет задачу из SQLite и возвращает удалённый объект.

Если задача не найдена, API отвечает `404 Not Found`.

## Pydantic-модели

Для тела запросов используются модели:

```python
class TaskCreate(BaseModel):
    title: str


class TaskUpdate(BaseModel):
    title: str
```

FastAPI использует их для чтения и проверки JSON-тела запроса перед вызовом обработчика endpoint.

## Хранение данных в SQLite

Путь к базе хранится отдельно:

```python
DATABASE_PATH = "tasks.db"
```

Обычное подключение выполняется через функцию `connect_database()`, которая только открывает соединение и возвращает объект `connection`.

Таблица создаётся отдельно через `init_database()`:

```sql
CREATE TABLE IF NOT EXISTS tasks
(
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT
)
```

В отличие от предыдущего проекта, данные сохраняются в файле `tasks.db` и остаются доступными после перезапуска приложения.

## Инициализация базы при запуске FastAPI

Для одноразовой подготовки базы используется `lifespan`:

```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    init_database()
    yield
```

Он передаётся при создании приложения:

```python
app = FastAPI(lifespan=lifespan)
```

Код до `yield` выполняется при запуске приложения, поэтому `CREATE TABLE IF NOT EXISTS` не приходится выполнять при каждом HTTP-запросе.

## Работа с соединениями

Каждый endpoint открывает собственное соединение с SQLite и закрывает его через `try / finally`:

```python
connection = connect_database()
try:
    ...
finally:
    connection.close()
```

Так соединение закрывается и при обычном `return`, и при `HTTPException`, и при неожиданной ошибке внутри работы с базой.

Для операций `INSERT`, `UPDATE` и `DELETE` изменения сохраняются через:

```python
connection.commit()
```

## Как запустить

Перейти в папку проекта:

```bash
cd 16_task_api_sqlite
```

Установить FastAPI со стандартными зависимостями:

```bash
python -m pip install "fastapi[standard]"
```

Запустить сервер разработки:

```bash
python -m fastapi dev task_api_sqlite.py
```

После запуска API доступен по адресу `http://127.0.0.1:8000`, а автоматическая документация Swagger — по адресу `http://127.0.0.1:8000/docs`.

## Автоматические тесты

Для запуска тестов нужен `pytest`:

```bash
python -m pip install pytest
```

Запускать тесты нужно из папки проекта:

```bash
python -m pytest -v
```

Проект содержит 3 теста. Они проверяют:

* создание задачи через `POST /tasks` и статус `201`;
* `404` при запросе отсутствующей задачи;
* удаление существующей задачи через `DELETE /tasks/{task_id}`.

В тестах используются:

* `fastapi.testclient.TestClient`;
* `pytest`;
* fixture с `autouse=True`;
* `tmp_path` для отдельной временной SQLite-базы каждого теста;
* `monkeypatch` для временной подмены `DATABASE_PATH`;
* `init_database()` для создания таблицы в тестовой базе;
* две стартовые задачи, которые добавляются перед каждым тестом;
* изоляция тестов от обычного файла `tasks.db`.

Последний результат тестов:

```text
3 passed
```

## Статус проекта

Проект завершён как учебный мини-проект для закрепления связки FastAPI + SQLite без ORM: `sqlite3`, постоянное хранение данных, полный CRUD, параметрические SQL-запросы, `fetchone()`, `fetchall()`, `cursor.lastrowid`, `commit()`, `try / finally`, управление временем жизни соединения, отдельная инициализация базы через `lifespan`, `asynccontextmanager`, `TestClient`, `pytest`, `tmp_path`, `monkeypatch` и изоляция тестовой базы.
