# Task API SQLite

REST API для управления задачами на FastAPI с постоянным хранением данных в SQLite.

Это продолжение предыдущего Task API: HTTP-интерфейс остался простым, но данные теперь сохраняются между запусками приложения.

## Что реализовано

- `GET /tasks`;
- `GET /tasks/{id}`;
- `POST /tasks`;
- `PATCH /tasks/{id}`;
- `DELETE /tasks/{id}`;
- `404 Not Found` для отсутствующих записей;
- SQLite через стандартный модуль `sqlite3`;
- параметрические SQL-запросы;
- автоматическое создание таблицы при запуске через FastAPI lifespan;
- закрытие соединений через `try/finally`.

## Тестирование

Тесты запускаются не на обычном `tasks.db`, а на отдельной временной базе. Путь к ней подменяется через `monkeypatch`, а `tmp_path` создаёт изолированный файл базы для каждого теста.

Сейчас есть проверки создания задачи, ответа 404 и удаления. Покрытие API планируется расширить.

## Запуск

1. `python -m pip install -r requirements.txt`
2. `python -m fastapi dev task_api_sqlite.py`

Swagger: `http://127.0.0.1:8000/docs`

Тесты: `python -m pytest -v`
