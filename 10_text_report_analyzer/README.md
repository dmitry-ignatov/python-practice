# 10 Text Report Analyzer

Консольная программа для анализа текстовых файлов и создания подробного отчёта на Python.

Проект сделан для закрепления работы с текстом, словарями, файлами, путями через `pathlib`, обработкой ошибок и разделением программы на функции.

Программа принимает путь к `.txt`-файлу, анализирует его содержимое, выводит результат в консоль и сохраняет такой же отчёт рядом с исходным файлом.

## Возможности

* ввод пути к текстовому файлу через консоль;
* удаление лишних пробелов вокруг введённого пути;
* проверка существования пути;
* проверка, что путь ведёт именно к файлу;
* разрешение только файлов формата `.txt` без учёта регистра;
* чтение файла в кодировке UTF-8;
* нормализация слов:

  * перевод в нижний регистр;
  * удаление знаков препинания по краям слов;
  * пропуск пустых результатов;
* подсчёт количества символов;
* подсчёт количества символов без пробельных символов;
* подсчёт количества слов;
* подсчёт количества строк;
* определение самого длинного и самого короткого слова;
* подсчёт количества разных слов;
* поиск до трёх самых частых повторяющихся слов;
* вывод количества повторений для каждого слова из топа;
* формирование единого отчёта для консоли и файла;
* сохранение отчёта рядом с исходным файлом;
* обработка ошибок кодировки, чтения, доступа и сохранения;
* структура программы через функции;
* запуск через `main()` и `if __name__ == "__main__"`.

## Что содержит отчёт

Программа выводит:

```text
Количество символов
Количество слов
Количество символов без пробелов
Самое длинное слово
Самое короткое слово
Количество строк
Топ повторяющихся слов и количество их повторений
Количество уникальных слов
```

Под уникальными словами в отчёте понимается количество разных нормализованных слов в тексте.

## Сохранение отчёта

Отчёт сохраняется в ту же папку, где находится выбранный текстовый файл.

К имени исходного файла добавляется окончание `_report`.

Например:

```text
article.txt
article_report.txt
```

Для построения нового пути используются свойства объекта `Path`:

```python
report_path = text_path.parent / f"{text_path.stem}_report{text_path.suffix}"
```

## Обработка ошибок

Программа не завершается с необработанной ошибкой при следующих ситуациях:

* путь не существует;
* вместо файла выбрана папка;
* выбран файл другого формата;
* файл нельзя прочитать как UTF-8;
* нет доступа к чтению файла;
* нет доступа к записи отчёта;
* произошла другая системная ошибка чтения или сохранения;
* файл пустой или не содержит слов после нормализации.

После ошибки чтения программа повторно предлагает выбрать файл.

Если отчёт удалось сформировать, но не удалось сохранить, он всё равно остаётся выведенным в консоль.

## Как запустить

Перейти в папку проекта:

```bash
cd 10_text_report_analyzer
```

Запустить программу:

```bash
python text_report_analyzer.py
```

После запуска ввести полный или относительный путь к нужному `.txt`-файлу.
