# Text Report Analyzer

Инструмент для анализа текстового файла и создания отчёта рядом с исходным файлом.

Программа считает строки, слова и символы, находит самые короткие и длинные слова, количество уникальных слов и несколько самых частых повторов.

## Особенности

- проверка пути и расширения;
- UTF-8;
- нормализация слов;
- словарь частот;
- обработка ошибок чтения, доступа и кодировки.

## Запуск

`python text_report_analyzer.py`
