# 14 Weather Reporter

Консольная программа для получения текущей погоды и прогноза на три дня через Open-Meteo API и создания текстового отчёта на Python.

Проект сделан для закрепления работы с несколькими REST API, HTTP-запросами через библиотеку `requests`, JSON-ответами, датой и временем, обработкой сетевых ошибок и автоматическим тестированием через `pytest`.

Пользователь вводит название города. Сначала программа получает координаты города через Open-Meteo Geocoding API, затем использует их для запроса прогноза погоды. Готовый отчёт выводится в консоль и сохраняется в отдельный `.txt`-файл.

## Формат ввода

Программа запрашивает название города:

```text
Введите название города: Рязань
```

Пробелы по краям строки удаляются через `.strip()`.

Если пользователь вводит пустую строку, программа выводит:

```text
Введен пустой текст
```

и повторяет ввод.

## Возможности

* ввод и нормализация названия города;
* поиск города через Open-Meteo Geocoding API;
* получение широты и долготы найденного города;
* получение текущей погоды через Open-Meteo Forecast API;
* получение прогноза на три дня;
* преобразование погодных кодов WMO в русские описания;
* обработка неизвестного погодного кода;
* преобразование даты и времени в удобный формат;
* вывод отчёта в консоль;
* сохранение отчёта в `.txt`-файл с названием города и временем создания;
* ограничение времени ожидания HTTP-запросов через `timeout`;
* обработка HTTP-ошибок, сетевых и файловых исключений;
* автоматические тесты через `pytest`.

## Данные в отчёте

Программа показывает информацию о городе:

* название;
* страну;
* широту;
* долготу.

Для текущей погоды выводятся:

* дата и время;
* температура;
* ощущаемая температура;
* погодное состояние;
* скорость ветра.

Для каждого из трёх дней прогноза выводятся:

* дата;
* погодное состояние;
* минимальная температура;
* максимальная температура;
* максимальная вероятность осадков.

## Погодные коды

Open-Meteo возвращает погодное состояние в виде числового WMO-кода.

Программа преобразует известные коды в русские описания, например:

```text
0  -> ясно
3  -> пасмурно
61 -> слабый дождь
95 -> гроза
99 -> гроза с сильным градом
```

Если приходит неизвестный код, программа использует описание:

```text
неизвестное погодное состояние
```

## Обработка ошибок

Если город не найден, программа выводит:

```text
Города с таким названием нет
```

Если API возвращает HTTP-код, отличный от `200`:

```text
Ошибка запроса
```

Если превышено время ожидания запроса:

```text
Превышено время ожидания
```

При другой ошибке соединения:

```text
Ошибка соединения
```

При невозможности сохранить отчёт программа сообщает об отсутствии доступа или другой файловой ошибке.

## Пример работы

Пример ввода:

```text
Введите название города: Рязань
```

Пример части отчёта:

```text
Название города: Рязань
Страна: Россия
Широта: 54.625
Долгота: 39.6875

Текущая дата и время:
2026-08-07 16:45

Текущая погода:
Температура: 31.3 °C
Ощущается как: 33.0 °C
Состояние: пасмурно
Скорость ветра: 12.3 km/h

Прогноз на 3 дня

Дата: 2026-08-07
Состояние: гроза
Минимальная температура: 20.6 °C
Максимальная температура: 32.2 °C
Вероятность осадков: 28 %
```

Значения в примере приведены только для демонстрации формата. Фактическая погода зависит от данных Open-Meteo на момент запроса.

После успешного выполнения отчёт сохраняется рядом с программой. Имя файла имеет формат:

```text
Рязань_2026.08.08_14-30_weather_report.txt
```

## Как запустить

Перейти в папку проекта:

```bash
cd 14_weather_reporter
```

Установить библиотеку `requests`:

```bash
python -m pip install requests
```

Запустить программу:

```bash
python weather_reporter.py
```

Для выполнения запросов требуется подключение к интернету.

## Автоматические тесты

Для запуска тестов нужен `pytest`:

```bash
python -m pip install pytest
```

Запускать тесты нужно из папки проекта:

```bash
python -m pytest -v
```

Проект содержит 18 тестов. Они проверяют:

* нормализацию названия города и повторный ввод после пустой строки;
* успешный ответ Geocoding API;
* отсутствие результатов поиска города;
* обработку ошибочного HTTP-кода при поиске города;
* обработку `requests.Timeout` и `requests.RequestException` для обоих API-запросов;
* успешный ответ Forecast API и ошибочный HTTP-код;
* преобразование текущего и дневных погодных кодов;
* обработку неизвестных погодных кодов;
* формирование технического словаря с данными;
* создание готового текстового отчёта;
* сохранение отчёта во временную папку и проверку записанного содержимого.

В тестах используются:

* `assert`;
* собственные фикстуры `@pytest.fixture`;
* класс `FakeResponse` для имитации объекта ответа `requests.Response`;
* встроенные фикстуры `monkeypatch`, `capsys` и `tmp_path`;
* подмена `requests.get()` без настоящего обращения к интернету;
* подмена встроенной функции `input()`;
* `iter()` и `next()` для последовательной передачи нескольких значений;
* `Path.glob()` для поиска созданного тестового файла.

## Статус проекта

Проект завершён как учебный мини-проект для закрепления REST API, последовательной работы с двумя HTTP-запросами, библиотеки `requests`, JSON-ответов, `timeout`, исключений `requests.Timeout` и `requests.RequestException`, `datetime.strptime()`, `strftime()`, `pathlib`, WMO-кодов погоды и тестирования внешних зависимостей через `pytest`, `monkeypatch`, `capsys` и `tmp_path`.
