# Weather Reporter

Консольная программа для получения текущей погоды и прогноза на три дня через Open-Meteo.

Запрос выполняется в два этапа: сначала Geocoding API находит город и его координаты, затем Forecast API возвращает погоду для найденной точки.

## Возможности

- поиск города;
- два последовательных REST-запроса;
- текущая температура и ощущаемая температура;
- состояние погоды и скорость ветра;
- трёхдневный прогноз;
- преобразование WMO-кодов в текст;
- обработка timeout, сетевых ошибок и пустого результата;
- сохранение отчёта в файл.

## Тесты

Основная логика покрыта 18 тестами. Для HTTP-ответов используется собственный `FakeResponse`, запросы подменяются через `monkeypatch`, файловые операции проверяются через `tmp_path`.

## Запуск

1. `python -m pip install -r requirements.txt`
2. `python weather_reporter.py`

Тесты: `python -m pytest -v`
