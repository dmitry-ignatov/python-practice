# 07 Notes Database

Консольный менеджер заметок на Python с хранением данных в SQLite.

Программа позволяет добавлять заметки, просматривать список, изменять и удалять заметки, искать их по тексту и дате создания, смотреть статистику, а также очищать всю базу заметок.

## Возможности

* добавление заметок;
* проверка пустого текста заметки;
* нормализация лишних пробелов;
* просмотр списка заметок;
* отображение даты и времени создания заметки;
* удаление заметки по номеру;
* изменение текста заметки;
* поиск заметок:

  * по тексту;
  * по дате создания;
* подсчёт общего количества заметок;
* очистка всех заметок с подтверждением;
* хранение данных в SQLite-базе;
* автоматическое создание таблицы при запуске программы;
* обработка неверного ввода команд и номеров заметок.

## Структура базы данных

Заметки хранятся в таблице `notes`.

Структура таблицы:

```sql
id INTEGER PRIMARY KEY AUTOINCREMENT,
text TEXT,
created_at TEXT
```

Поля:

* `id` — уникальный номер заметки;
* `text` — текст заметки;
* `created_at` — дата и время создания заметки.

## Сохранение данных

Данные сохраняются в файл базы данных:

```text
notes.db
```

Файл `notes.db` не добавляется в Git, потому что это пользовательские данные.

## Как запустить

Перейти в папку проекта:

```bash
cd 07_notes_database
```

Запустить программу:

```bash
python main.py
```
