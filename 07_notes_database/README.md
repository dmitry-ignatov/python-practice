# Notes Database

Консольное CRUD-приложение для заметок с хранением в SQLite.

Можно создавать, просматривать, изменять и удалять заметки, искать их по тексту и дате, смотреть статистику и очищать базу.

## Техническая часть

Используется стандартный модуль `sqlite3`: создание таблицы, `INSERT`, `SELECT`, `UPDATE`, `DELETE`, `COUNT(*)`, параметрические запросы, `fetchone()` и `fetchall()`.

## Запуск

`python main.py`

База `notes.db` создаётся автоматически.
