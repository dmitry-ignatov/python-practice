# Log Analyzer

Консольная программа для разбора лог-файлов.

Строки лога разделяются на дату и время, уровень и сообщение. Можно фильтровать записи по уровню, тексту и дате, получать статистику по INFO/WARNING/ERROR и находить самые частые сообщения об ошибках.

Повреждённые строки учитываются отдельно и не останавливают обработку файла.

## Используется

`pathlib`, `datetime`, `collections.Counter`, фильтрация данных и обработка файловых ошибок.

## Запуск

`python log_analyzer.py`
