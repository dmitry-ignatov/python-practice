# Text Cleaner

Учебный консольный проект на Python.

Программа принимает строки от пользователя, очищает их, убирает повторы, сортирует результат и сохраняет очищенный список в `.txt` файл.

## Что делает программа

* принимает строки через `input()`
* завершает ввод по команде `stop`
* убирает лишние пробелы по краям и внутри строки
* не добавляет пустые строки
* не добавляет повторяющиеся строки без учёта регистра
* сортирует строки без учёта регистра
* выводит строки списком с номерами
* показывает количество добавленных строк
* спрашивает имя файла для сохранения результата
* автоматически добавляет расширение `.txt`, если пользователь ввёл имя файла без расширения
* не сохраняет файл, если строк нет


## Как запустить

```bash
python text_cleaner.py
```

## Пример работы

```text
Введите текст:   кот      собака
Введите текст: кот собака
Такая строка уже есть
Введите текст: Яблоко
Введите текст: stop

1. кот собака
2. Яблоко

Количество строк: 2
Введите имя файла: result

Текст сохранен в result.txt
```

## Файлы результата

Программа создаёт `.txt` файлы с очищенными строками.
