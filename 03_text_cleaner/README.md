# Text Cleaner

Консольный инструмент для очистки списка строк.

Программа убирает лишние пробелы, пропускает пустые значения, не сохраняет дубликаты без учёта регистра, сортирует результат и записывает его в текстовый файл.

## Основные задачи

- нормализация строк;
- поиск повторов;
- сортировка;
- нумерация через `enumerate()`;
- работа с текстовыми файлами.

## Запуск

`python text_cleaner.py`
