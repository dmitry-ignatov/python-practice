# GitHub Repo Reporter

Консольная программа, которая получает информацию о репозитории через GitHub REST API и сохраняет её в текстовый отчёт.

На вход подаётся имя в формате `owner/repository`. Программа показывает название, описание, основной язык, количество звёзд, форков, открытых задач и дату последнего обновления.

## Что учтено

- проверка формата имени репозитория;
- запрос через `requests` с timeout;
- ответы 200 и 404;
- сетевые ошибки;
- обработка JSON;
- преобразование даты;
- сохранение отчёта в файл.

## Тесты

Тесты проверяют формирование отчёта, ввод пользователя и сетевые сценарии через `monkeypatch` и `capsys`.

## Запуск

1. `python -m pip install -r requirements.txt`
2. `python github_repo_reporter.py`

Тесты: `python -m pytest -v`
