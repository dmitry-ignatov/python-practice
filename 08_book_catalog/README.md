# 08 Book Catalog

Консольный каталог книг на Python с хранением данных в SQLite.

Проект сделан для закрепления материала из прошлого проекта `07_notes_database`. По структуре он похож на менеджер заметок, но использует другую предметную область: вместо заметок программа хранит книги, авторов и статус чтения.

Программа позволяет добавлять книги, просматривать каталог, удалять книги, искать их по названию, автору или статусу, изменять статус чтения, смотреть статистику, а также очищать весь каталог.

## Возможности

* добавление книг;
* проверка пустого названия книги;
* проверка пустого имени автора;
* нормализация лишних пробелов;
* выбор статуса книги:

  * `Запланировано`;
  * `Читаю`;
  * `Прочтено`;
* просмотр всех книг в каталоге;
* удаление книги по номеру;
* поиск книг:

  * по названию;
  * по автору;
  * по статусу;
* изменение статуса книги;
* подсчёт статистики:

  * всего книг;
  * книг со статусом `Запланировано`;
  * книг со статусом `Читаю`;
  * книг со статусом `Прочтено`;
* очистка всего каталога с подтверждением;
* хранение данных в SQLite-базе;
* автоматическое создание таблицы при запуске программы;
* обработка неверного ввода команд, номеров книг и статусов.

## Структура базы данных

Книги хранятся в таблице `books`.

Структура таблицы:

```sql
id INTEGER PRIMARY KEY AUTOINCREMENT,
title TEXT,
author TEXT,
status TEXT
```

Поля:

* `id` — уникальный номер книги;
* `title` — название книги;
* `author` — автор книги;
* `status` — статус чтения книги.

## Сохранение данных

Данные сохраняются в файл базы данных:

```text
books.db
```

Файл `books.db` не добавляется в Git, потому что это пользовательские данные.

## Как запустить

Перейти в папку проекта:

```bash
cd 08_book_catalog
```

Запустить программу:

```bash
python main.py
```
