# Book Catalog

Консольный каталог книг на SQLite.

Для каждой книги хранятся название, автор и статус чтения. Есть добавление, удаление, поиск, изменение статуса и статистика по каталогу.

Проект сделан после Notes Database, чтобы повторить CRUD и работу с SQLite уже на другой задаче.

## Запуск

`python main.py`

Данные сохраняются в `books.db`.
