# Password Checker

Консольная программа для оценки надёжности пароля.

Проверяются длина, регистр букв, цифры, спецсимволы, пробелы и совпадение со списком простых паролей. По результатам программа считает балл и выводит рекомендации.

## Что используется

Строковые методы Python, `any()`, условия, списки и отдельные функции для проверок.

## Запуск

`python main.py`
