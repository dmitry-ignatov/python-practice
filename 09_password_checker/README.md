# 09 Password Checker

Консольная программа для проверки надёжности пароля на Python.

Проект сделан для закрепления работы со строками, условиями, функциями, проверками символов и подсчётом баллов. В отличие от предыдущих проектов на SQLite, этот проект не использует базу данных и сосредоточен на логике проверки введённых данных.

Программа принимает пароль, проверяет его по нескольким критериям, считает итоговый балл, определяет уровень надёжности и выводит рекомендации по улучшению пароля.

## Возможности

* ввод пароля через консоль;
* проверка длины пароля;
* проверка наличия больших букв;
* проверка наличия маленьких букв;
* проверка наличия цифр;
* проверка наличия спецсимволов;
* проверка наличия пробелов;
* проверка пароля по списку простых паролей;
* подсчёт итогового количества баллов;
* определение уровня надёжности:

  * слабый пароль;
  * средний пароль;
  * сильный пароль;
* вывод подробного результата проверки;
* вывод рекомендаций по улучшению пароля;
* структура программы через функции;
* запуск через `main()` и `if __name__ == "__main__"`.

## Система оценки

Максимальная оценка пароля — 10 баллов.

Критерии:

```text
Длина пароля:
меньше 8 символов       — 0 баллов
8–11 символов           — 2 балла
12 и больше символов    — 3 балла

Маленькие буквы:
есть хотя бы одна       — 1 балл
нет                     — 0 баллов

Большие буквы:
есть хотя бы одна       — 1 балл
нет                     — 0 баллов

Цифры:
есть хотя бы одна       — 1 балл
нет                     — 0 баллов

Спецсимволы:
есть хотя бы один       — 2 балла
нет                     — 0 баллов

Пробелы:
нет пробелов            — 1 балл
есть пробелы            — 0 баллов

Простые пароли:
пароль не простой       — 1 балл
пароль простой          — 0 баллов
```

Итоговая шкала:

```text
0–3 балла    — слабый пароль
4–6 баллов   — средний пароль
7–10 баллов  — сильный пароль
```

## Простые пароли

Программа проверяет пароль по списку простых вариантов:

```text
password
qwerty
qwerty123
123456
12345678
111111
admin
admin123
пароль
йцукен
```

Проверка выполняется без учёта регистра, поэтому `Admin`, `ADMIN` и `admin` считаются одним и тем же простым паролем.

## Как запустить

Перейти в папку проекта:

```bash
cd 09_password_checker
```

Запустить программу:

```bash
python main.py
```
