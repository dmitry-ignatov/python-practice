# Expense Analyzer

Консольная программа для учёта личных расходов.

Можно добавлять, изменять и удалять расходы, смотреть статистику, очищать список, сохранять данные в файл и загружать их при следующем запуске. Отдельно можно сформировать текстовый отчёт.

## Что используется

- функции и работа со списками;
- циклы и условия;
- обработка пользовательского ввода;
- try/except;
- чтение и запись файлов.

## Запуск

Из папки проекта:

`python expense_analyzer.py`
