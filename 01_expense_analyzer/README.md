# Анализатор расходов

Учебный консольный проект на Python.

## Что делает программа

Программа принимает список расходов и выводит:

- общую сумму расходов
- средний расход
- самый большой расход
- самый маленький расход
- количество расходов выше среднего

## Что я практиковал

- функции
- параметры функций
- return
- списки
- циклы for
- ввод данных через input()
- базовые вычисления
- разделение программы на небольшие части

## Как запустить

```bash
python expense_analyzer.py
