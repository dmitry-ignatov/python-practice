# Анализатор расходов

Учебный консольный проект на Python.

Программа позволяет вести простой список расходов, смотреть статистику, сохранять данные в файл и загружать их обратно.

## Что делает программа

Программа принимает расходы и выводит:

* общую сумму расходов;
* средний расход;
* самый большой расход;
* самый маленький расход;
* количество расходов выше среднего.

## Возможности

* добавление расходов через меню;
* проверка, чтобы расход был больше нуля;
* просмотр статистики;
* просмотр всех расходов;
* удаление выбранного расхода;
* изменение выбранного расхода;
* очистка списка расходов;
* сохранение расходов в файл;
* загрузка расходов из файла;
* создание отдельного текстового отчёта.

## Работа с файлами

При сохранении программа создаёт два файла:

* `expenses.txt` — файл с данными для загрузки обратно в программу;
* `expenses_report.txt` — текстовый отчёт для просмотра человеком.

Файл `expenses.txt` хранит расходы в простом формате: одно число на строку.

## Обработка ошибок

Программа обрабатывает несколько обычных ситуаций:

* ввод нечислового значения;
* ввод нулевого или отрицательного расхода;
* неверный номер расхода при удалении или изменении;
* отсутствие файла `expenses.txt`;
* пустой файл `expenses.txt`;
* некорректные данные в файле.
