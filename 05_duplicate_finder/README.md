# Duplicate Finder

Консольная программа для поиска одинаковых файлов в выбранной папке и всех её подпапках.

Чтобы не считать хэш для каждого файла без необходимости, поиск идёт в два этапа: сначала файлы группируются по размеру, а затем файлы одинакового размера сравниваются по SHA-256.

Файлы читаются блоками по 64 КБ, поэтому программа не загружает большой файл целиком в память.

## Возможности

- рекурсивный поиск через `Path.rglob()`;
- группировка файлов по размеру;
- SHA-256 для проверки содержимого;
- обработка ошибок чтения;
- вывод относительных путей;
- подсчёт групп дубликатов и лишних копий.

## Запуск

`python duplicate_finder.py`
