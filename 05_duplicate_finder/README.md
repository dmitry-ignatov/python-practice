# Duplicate Finder

Консольная Python-программа для поиска одинаковых файлов в выбранной папке и её вложенных папках.

Программа сравнивает файлы не только по размеру, но и по содержимому через SHA-256, поэтому находит именно настоящие дубликаты.

## Что делает программа

* принимает путь к папке от пользователя;
* проверяет, что путь существует и является папкой;
* ищет файлы во всех вложенных папках;
* сначала группирует файлы по размеру;
* затем сравнивает файлы одинакового размера по SHA-256;
* читает файлы блоками, чтобы не загружать большие файлы целиком в память;
* обрабатывает ошибки доступа к файлам;
* выводит найденные группы дубликатов;
* показывает относительные пути файлов;
* выводит количество групп дубликатов и количество лишних копий.

## Как запустить

Запустить программу можно из папки проекта:

```bash
python duplicate_finder.py
```

После запуска программа попросит ввести путь к папке:

```text
Введите путь к папке:
```

Пример:

```text
C:\Users\User\Desktop\test_folder
```

## Пример вывода

```text
Проверяемая папка: C:\Users\User\Desktop\test_folder

1. Дубликаты:

copy.txt (путь - copy.txt)
copy2.txt (путь - nested\copy2.txt)

Всего групп дубликатов: 1
Всего лишних копий: 1
```

Если одинаковые файлы не найдены:

```text
Одинаковые файлы не найдены
```
