# Folder Reporter

Программа анализирует выбранную папку и формирует по ней текстовый отчёт.

Проверяется корректность пути, отдельно считаются файлы и подпапки, файлы группируются по расширениям и категориям. Учтены пустые папки и ошибки доступа.

## Что используется

`pathlib`, словари, сортировка, вложенные циклы, обработка исключений и работа с файловой системой.

## Запуск

`python folder_reporter.py`
