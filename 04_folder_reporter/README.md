# Folder Reporter

Учебный консольный проект на Python для анализа содержимого выбранной папки и создания текстового отчёта.

## Что делает программа

Программа:

* принимает путь к папке;
* проверяет существование указанного пути;
* проверяет, что путь ведёт именно к папке;
* получает список файлов и подпапок;
* сортирует содержимое по имени без учёта регистра;
* нумерует найденные элементы;
* отличает файлы от папок;
* определяет расширения файлов;
* распределяет файлы по категориям;
* считает количество файлов и папок;
* показывает файлы внутри каждой категории;
* выводит отчёт в консоль;
* сохраняет отчёт в текстовый файл.

## Категории файлов

Программа распределяет файлы по следующим категориям:

* `image` — `.png`, `.jpg`;
* `audio` — `.mp3`, `.wav`;
* `document` — `.pdf`, `.txt`;
* `archive` — `.zip`, `.rar`;
* `unknown` — остальные расширения и файлы без расширения.

## Обработка особых случаев

Программа обрабатывает:

* несуществующий путь;
* путь к файлу вместо папки;
* пустую папку;
* отсутствие доступа к содержимому папки;
* ошибку сохранения отчёта;
* пустое имя файла отчёта.

Если имя отчёта не введено, используется имя:

```text
report.txt
```

Если расширение `.txt` не указано, программа добавляет его автоматически.

## Как запустить

Перейдите в папку проекта и выполните:

```bash
python folder_reporter.py
```

После запуска:

1. Введите путь к папке для анализа.
2. Просмотрите сформированный отчёт.
3. Введите имя файла для сохранения.
4. Откройте созданный текстовый отчёт.

## Используемые технологии

* Python 3
* стандартный модуль `pathlib`

Сторонние библиотеки не требуются.
