# File Sorter

Небольшая консольная программа, которая принимает имена файлов и распределяет их по категориям в зависимости от расширения.

Ввод продолжается до команды `stop`. После этого программа показывает файлы по категориям и их количество.

## В проекте

- строки и методы строк;
- списки и словари;
- циклы;
- перебор словаря через `.items()`;
- проверка пустого ввода.

## Запуск

`python file_sorter.py`
