# File Sorter

Учебный консольный проект на Python.

## Что делает программа

Программа принимает имена файлов от пользователя и распределяет их по категориям на основе расширения файла.

Поддерживаемые категории:

* image
* audio
* document
* archive
* unknown

Ввод завершается командой `stop`.

## Возможности

* ввод имён файлов через консоль
* завершение ввода командой `stop`
* команда `stop` работает без учёта регистра
* защита от добавления пустого имени файла
* определение категории файла по расширению
* сортировка файлов по категориям
* вывод файлов в каждой категории
* вывод сообщения, если в категории нет файлов
* подсчёт общего количества файлов
* подсчёт количества файлов в каждой категории
* обработка случая, когда пользователь сразу вводит `stop`

## Поддерживаемые расширения

### image

* `.png`
* `.jpg`

### audio

* `.mp3`
* `.wav`

### document

* `.pdf`
* `.txt`

### archive

* `.zip`
* `.rar`

Все остальные расширения попадают в категорию `unknown`.

## Структура программы

Программа разделена на несколько функций:

* `get_category()` — определяет категорию файла
* `get_files()` — получает список файлов от пользователя
* `sort_files()` — сортирует файлы по категориям
* `show_results()` — выводит результат сортировки и статистику

## Как запустить

```bash
python file_sorter.py
```
