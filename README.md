# Python Practice

Учебный репозиторий с моими первыми проектами на Python.

Здесь я сохраняю небольшие консольные программы, чтобы закреплять новые темы на практике и отслеживать свой прогресс.

## Проекты

### [01_expense_analyzer](01_expense_analyzer)

Консольный анализатор расходов.

Программа позволяет:

* добавлять расходы;
* просматривать список и статистику;
* удалять и изменять расходы;
* очищать список;
* сохранять данные в файл;
* загружать данные из файла;
* создавать отдельный текстовый отчёт.

Основные темы: функции, списки, циклы, условия, `try / except`, сохранение и загрузка данных.

---

### [02_file_sorter](02_file_sorter)

Консольная программа для распределения введённых имён файлов по категориям.

Программа:

* принимает имена файлов через консоль;
* завершает ввод командой `stop`;
* определяет категорию по расширению;
* распределяет файлы по словарю категорий;
* выводит файлы и их количество в каждой категории;
* обрабатывает пустой ввод.

Основные темы: функции, списки, словари, циклы, строковые методы и перебор словаря через `.items()`.

---

### [03_text_cleaner](03_text_cleaner)

Консольный очиститель и сортировщик строк.

Программа:

* принимает строки через консоль;
* удаляет лишние пробелы;
* не добавляет пустые строки;
* не добавляет повторы без учёта регистра;
* сортирует результат;
* выводит строки с нумерацией;
* сохраняет результат в `.txt`-файл.

Основные темы: функции, списки, нормализация текста, проверка повторов, сортировка, `enumerate()` и работа с файлами.

---

### [04_folder_reporter](04_folder_reporter)

Консольный инструмент для анализа содержимого папки и создания текстового отчёта.

Программа:

* принимает путь к папке;
* проверяет существование пути;
* отличает файл от папки;
* получает и сортирует содержимое папки;
* определяет расширения и категории файлов;
* считает файлы и подпапки;
* группирует файлы по категориям;
* выводит отчёт в консоль;
* сохраняет отчёт в `.txt`-файл;
* обрабатывает пустую папку, отсутствие доступа и ошибки сохранения.

Основные темы: `pathlib`, класс `Path`, словари, вложенные циклы, сортировка через `key`, обработка ошибок, `main()` и `if __name__ == "__main__":`.

---

### [05_duplicate_finder](05_duplicate_finder)

Консольная программа для поиска одинаковых файлов в выбранной папке и её вложенных папках.

Программа:

* принимает путь к папке;
* проверяет существование пути;
* ищет файлы во вложенных папках;
* сначала группирует файлы по размеру;
* затем сравнивает файлы одинакового размера по SHA-256;
* читает файлы блоками;
* обрабатывает ошибки доступа к файлам;
* выводит найденные группы дубликатов;
* показывает относительные пути файлов;
* выводит количество групп дубликатов и лишних копий.

Основные темы: `pathlib`, `rglob()`, `hashlib`, SHA-256, чтение файлов блоками, обработка `OSError`, словари и группировка данных.


## Как запускать проекты

Каждый проект находится в отдельной папке и содержит собственный `README.md` с подробным описанием.

### Expense Analyzer

```bash
cd 01_expense_analyzer
python expense_analyzer.py
```

### File Sorter

```bash
cd 02_file_sorter
python file_sorter.py
```

### Text Cleaner

```bash
cd 03_text_cleaner
python text_cleaner.py
```

### Folder Reporter

```bash
cd 04_folder_reporter
python folder_reporter.py
```

### Duplicate Finder

```bash
cd 05_duplicate_finder
python duplicate_finder.py
```
