# Python Practice

Учебный репозиторий с моими первыми Python-программами.

## Цель

Я изучаю Python с нуля и сохраняю здесь небольшие учебные проекты, чтобы отслеживать прогресс


## Проекты

### 01_expense_analyzer

Консольная программа для анализа расходов.

Программа позволяет:

* добавлять расходы;
* смотреть статистику;
* выводить список расходов;
* удалять и изменять расходы;
* очищать список;
* сохранять данные в файл;
* загружать данные из файла;
* создавать текстовый отчёт.

Что практиковалось:

* функции;
* списки;
* циклы;
* условия;
* обработка ошибок через `try / except`;
* работа с файлами;
* сохранение и загрузка данных.

---

### 02_file_sorter

Консольная программа для сортировки имён файлов по категориям.

Программа распределяет файлы по расширениям:

* `image`
* `audio`
* `document`
* `archive`
* `unknown`

Что умеет программа:

* принимать имена файлов через консоль;
* завершать ввод командой `stop`;
* определять категорию файла по расширению;
* сортировать файлы по словарю категорий;
* выводить файлы в каждой категории;
* показывать количество файлов по категориям;
* обрабатывать пустой ввод и пустые категории.

Что практиковалось:

* функции;
* списки;
* словари;
* методы строк `.lower()`, `.endswith()`, `.join()`;
* перебор словаря через `.items()`;
* разделение программы на логические части.

---

### 03_text_cleaner

Консольная программа для очистки и упорядочивания строк текста.

Программа позволяет:

* вводить строки через консоль;
* завершать ввод командой `stop`;
* очищать строки от лишних пробелов;
* нормализовать пробелы внутри строки;
* не добавлять пустые строки;
* не добавлять повторы без учёта регистра;
* сохранять первую введённую версию строки;
* сортировать итоговый список;
* выводить строки с нумерацией;
* показывать количество строк.

Что практиковалось:

* функции;
* списки;
* проверка повторов;
* нормализация текста;
* методы `.split()`, `.join()`, `.lower()`;
* сортировка списка;
* `enumerate()`;
* разделение ввода, обработки и вывода.

## Как запускать проекты

Каждый проект находится в отдельной папке.

Пример запуска:

```bash
cd 01_expense_analyzer
python expense_analyzer.py
```

или:

```bash
cd 02_file_sorter
python file_sorter.py
```

или:

```bash
cd 03_text_cleaner
python text_cleaner.py
```
