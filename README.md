# Python Practice

Учебный репозиторий с моими первыми проектами на Python.

Здесь я сохраняю небольшие консольные программы, чтобы закреплять новые темы на практике и отслеживать свой прогресс.

## Проекты

### [01_expense_analyzer](01_expense_analyzer)

Консольный анализатор расходов.

Программа позволяет:

* добавлять расходы;
* просматривать список расходов;
* показывать статистику;
* удалять и изменять расходы;
* очищать список;
* сохранять данные в файл;
* загружать данные из файла;
* создавать отдельный текстовый отчёт.

Основные темы: функции, списки, циклы, условия, `try / except`, сохранение и загрузка данных.

---

### [02_file_sorter](02_file_sorter)

Консольная программа для распределения введённых имён файлов по категориям.

Программа позволяет:

* принимать имена файлов через консоль;
* завершать ввод командой `stop`;
* определять категорию по расширению;
* распределять файлы по словарю категорий;
* выводить файлы и их количество в каждой категории;
* обрабатывать пустой ввод.

Основные темы: функции, списки, словари, циклы, строковые методы и перебор словаря через `.items()`.

---

### [03_text_cleaner](03_text_cleaner)

Консольный очиститель и сортировщик строк.

Программа позволяет:

* принимать строки через консоль;
* удалять лишние пробелы;
* не добавлять пустые строки;
* не добавлять повторы без учёта регистра;
* сортировать результат;
* выводить строки с нумерацией;
* сохранять результат в `.txt`-файл.

Основные темы: функции, списки, нормализация текста, проверка повторов, сортировка, `enumerate()` и работа с файлами.

---

### [04_folder_reporter](04_folder_reporter)

Консольный инструмент для анализа содержимого папки и создания текстового отчёта.

Программа позволяет:

* принимать путь к папке;
* проверять существование пути;
* отличать файл от папки;
* получать и сортировать содержимое папки;
* определять расширения и категории файлов;
* считать файлы и подпапки;
* группировать файлы по категориям;
* выводить отчёт в консоль;
* сохранять отчёт в `.txt`-файл;
* обрабатывать пустую папку, отсутствие доступа и ошибки сохранения.

Основные темы: `pathlib`, класс `Path`, словари, вложенные циклы, сортировка через `key`, обработка ошибок, `main()` и `if __name__ == "__main__"`.

### [05_duplicate_finder](05_duplicate_finder)

Консольная программа для поиска одинаковых файлов в выбранной папке и её вложенных папках.

Программа позволяет:

* принимать путь к папке;
* проверять существование пути;
* искать файлы во вложенных папках;
* сначала группировать файлы по размеру;
* затем сравнивать файлы одинакового размера по SHA-256;
* читать файлы блоками;
* обрабатывать ошибки доступа к файлам;
* выводить найденные группы дубликатов;
* показывать относительные пути файлов;
* выводить количество групп дубликатов и лишних копий.

Основные темы: `pathlib`, `rglob()`, `hashlib`, SHA-256, чтение файлов блоками, обработка `OSError`, словари и группировка данных.

### [13_github_repo_reporter](13_github_repo_reporter)

Консольная программа для получения информации о репозитории через GitHub REST API и создания текстового отчёта.

Программа позволяет:

* получать и обрабатывать JSON-ответ;
* показывать название, описание, язык, звёзды, форки и открытые задачи;

* выводить отчёт в консоль;
* сохранять отчёт в `repository_report.txt`;
* обрабатывать HTTP-коды, сетевые и файловые ошибки;
* автоматически проверять основную логику через 7 тестов.

Основные темы: REST API, HTTP-запросы, библиотека `requests`, JSON-ответы, `timeout`, исключения `requests.Timeout` и `requests.RequestException`, `datetime.strptime()`, `strftime()`, `pathlib`, `pytest`, `monkeypatch`, `capsys`, `iter()` и `next()`.

### [14_weather_reporter](14_weather_reporter)

Консольная программа для получения текущей погоды и прогноза на три дня через Open-Meteo API и создания текстового отчёта.

Программа позволяет:

* принимать и нормализовать название города;
* искать город и получать его координаты через Open-Meteo Geocoding API;
* запрашивать текущую погоду и прогноз через Open-Meteo Forecast API;
* показывать температуру, ощущаемую температуру, состояние погоды и скорость ветра;
* формировать прогноз на три дня с минимальной и максимальной температурой и вероятностью осадков;
* преобразовывать WMO-коды погоды в русские описания;
* обрабатывать неизвестные погодные коды;
* выводить отчёт в консоль;
* сохранять отчёт в `.txt`-файл с названием города и временем создания;
* обрабатывать HTTP-коды, сетевые и файловые ошибки;
* автоматически проверять основную логику через 18 тестов.

Основные темы: REST API, последовательная работа с двумя HTTP-запросами, библиотека `requests`, JSON-ответы, query-параметры, `timeout`, `requests.Timeout`, `requests.RequestException`, `datetime.strptime()`, `strftime()`, `pathlib`, `pytest`, собственные фикстуры, `FakeResponse`, `monkeypatch`, `capsys` и `tmp_path`.

### [15_task_api](15_task_api)

Учебный REST API для управления задачами на FastAPI.

API позволяет:

* получать список всех задач;
* получать отдельную задачу по `id`;
* создавать задачи через `POST`;

* принимать JSON-тело запроса через Pydantic-модели;
* автоматически проверять основное поведение через 9 тестов с `TestClient`.

Основные темы: FastAPI, REST API, HTTP-методы, endpoint, path parameters, Pydantic `BaseModel`, request body, CRUD, `HTTPException`, коды `200`, `201` и `404`, `TestClient`, `pytest`, fixture с `autouse=True` и изоляция состояния тестов.

## Как запускать проекты

Каждый проект находится в отдельной папке и содержит собственный `README.md` с подробным описанием.

### Expense Analyzer

```bash
cd 01_expense_analyzer
python expense_analyzer.py
```

### File Sorter

```bash
cd 02_file_sorter
python file_sorter.py
```

### Text Cleaner

```bash
cd 03_text_cleaner
python text_cleaner.py
```

### Folder Reporter

```bash
cd 04_folder_reporter
python folder_reporter.py
```

### Duplicate Finder

```bash
cd 05_duplicate_finder
python duplicate_finder.py
```

### Personal Task Tracker

```bash
cd 06_personal_task_tracker
python main.py
```

### Notes Database

```bash
cd 07_notes_database
python main.py
```

### Book Catalog

```bash
cd 08_book_catalog
python main.py
```

### Password Checker

```bash
cd 09_password_checker
python main.py
```

### Text Report Analyzer

```bash
cd 10_text_report_analyzer
python text_report_analyzer.py
```

### Log Analyzer

```bash
cd 11_log_analyzer
python log_analyzer.py
```

### JSON Config Validator

```bash
cd 12_json_config_validator
python json_config_validator.py
```

Тесты проекта:

```bash

```

### GitHub Repo Reporter

```bash
cd 13_github_repo_reporter
python -m pip install requests
python github_repo_reporter.py
```

Тесты проекта:

```bash
python -m pytest
```

### Weather Reporter

```bash
cd 14_weather_reporter
python -m pip install requests
python weather_reporter.py
```

Тесты проекта:

```bash
python -m pytest -v
```

### Task API

```bash
cd 15_task_api
python -m pip install "fastapi[standard]"
python -m fastapi dev task_api.py
```

Документация API после запуска:

```text
http://127.0.0.1:8000/docs
```

Тесты проекта:

```bash
python -m pytest -v
```
