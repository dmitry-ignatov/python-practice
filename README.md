# Python Practice

Учебный репозиторий с моими первыми проектами на Python.

Здесь я сохраняю небольшие консольные программы, чтобы закреплять новые темы на практике и отслеживать свой прогресс.

## Проекты

### [01_expense_analyzer](01_expense_analyzer)

Консольный анализатор расходов.

Программа позволяет:

* добавлять расходы;
* просматривать список расходов;
* показывать статистику;
* удалять и изменять расходы;
* очищать список;
* сохранять данные в файл;
* загружать данные из файла;
* создавать отдельный текстовый отчёт.

Основные темы: функции, списки, циклы, условия, `try / except`, сохранение и загрузка данных.

---

### [02_file_sorter](02_file_sorter)

Консольная программа для распределения введённых имён файлов по категориям.

Программа позволяет:

* принимать имена файлов через консоль;
* завершать ввод командой `stop`;
* определять категорию по расширению;
* распределять файлы по словарю категорий;
* выводить файлы и их количество в каждой категории;
* обрабатывать пустой ввод.

Основные темы: функции, списки, словари, циклы, строковые методы и перебор словаря через `.items()`.

---

### [03_text_cleaner](03_text_cleaner)

Консольный очиститель и сортировщик строк.

Программа позволяет:

* принимать строки через консоль;
* удалять лишние пробелы;
* не добавлять пустые строки;
* не добавлять повторы без учёта регистра;
* сортировать результат;
* выводить строки с нумерацией;
* сохранять результат в `.txt`-файл.

Основные темы: функции, списки, нормализация текста, проверка повторов, сортировка, `enumerate()` и работа с файлами.

---

### [04_folder_reporter](04_folder_reporter)

Консольный инструмент для анализа содержимого папки и создания текстового отчёта.

Программа позволяет:

* принимать путь к папке;
* проверять существование пути;
* отличать файл от папки;
* получать и сортировать содержимое папки;
* определять расширения и категории файлов;
* считать файлы и подпапки;
* группировать файлы по категориям;
* выводить отчёт в консоль;
* сохранять отчёт в `.txt`-файл;
* обрабатывать пустую папку, отсутствие доступа и ошибки сохранения.

Основные темы: `pathlib`, класс `Path`, словари, вложенные циклы, сортировка через `key`, обработка ошибок, `main()` и `if __name__ == "__main__"`.

---

### [05_duplicate_finder](05_duplicate_finder)

Консольная программа для поиска одинаковых файлов в выбранной папке и её вложенных папках.

Программа позволяет:

* принимать путь к папке;
* проверять существование пути;
* искать файлы во вложенных папках;
* сначала группировать файлы по размеру;
* затем сравнивать файлы одинакового размера по SHA-256;
* читать файлы блоками;
* обрабатывать ошибки доступа к файлам;
* выводить найденные группы дубликатов;
* показывать относительные пути файлов;
* выводить количество групп дубликатов и лишних копий.

Основные темы: `pathlib`, `rglob()`, `hashlib`, SHA-256, чтение файлов блоками, обработка `OSError`, словари и группировка данных.

---

### [06_personal_task_tracker](06_personal_task_tracker)

Консольный менеджер задач на Python.

Программа позволяет:

* добавлять задачи;
* просматривать задачи со статусами `[ ]` и `[x]`;
* отмечать задачи выполненными;
* удалять задачи;
* изменять название задачи;
* показывать статистику по задачам;
* сохранять и загружать задачи из `tasks.json`;
* автоматически загружать задачи при запуске;
* подтверждать сохранение перед выходом;
* обрабатывать ошибки при загрузке JSON-файла.

Основные темы: функции, списки, словари, `try / except`, `json.dump`, `json.load`, `FileNotFoundError`, `json.JSONDecodeError`, `isinstance`, `set`, работа с файлами.

---

### [07_notes_database](07_notes_database)

Консольный менеджер заметок с хранением данных в SQLite.

Программа позволяет:

* добавлять заметки;
* просматривать список заметок;
* сохранять дату и время создания заметки;
* изменять заметки;
* удалять заметки;
* искать заметки по тексту и дате;
* показывать статистику;
* очищать все заметки;
* хранить данные в `notes.db`.

Основные темы: `sqlite3`, SQLite, `CREATE TABLE`, `INSERT`, `SELECT`, `UPDATE`, `DELETE`, `COUNT(*)`, `fetchall()`, `fetchone()`, параметрические SQL-запросы, функции, `try / except`, `main()` и `if __name__ == "__main__"`.

---

### [08_book_catalog](08_book_catalog)

Консольный каталог книг с хранением данных в SQLite.

Проект сделан для закрепления материала из `07_notes_database`: он повторяет SQLite CRUD и структуру консольного приложения на похожей, но отдельной задаче.

Программа позволяет:

* добавлять книги;
* просматривать список книг;
* хранить название, автора и статус чтения;
* удалять книги;
* искать книги по названию, автору и статусу;
* изменять статус книги;
* показывать статистику по статусам;
* очищать весь каталог;
* хранить данные в `books.db`.

Основные темы: `sqlite3`, SQLite, `CREATE TABLE`, `INSERT`, `SELECT`, `UPDATE`, `DELETE`, `fetchall()`, `fetchone()`, параметрические SQL-запросы, функции, меню, валидация ввода, `try / except`, `main()` и `if __name__ == "__main__"`.

## Как запускать проекты

Каждый проект находится в отдельной папке и содержит собственный `README.md` с подробным описанием.

### Expense Analyzer

```bash
cd 01_expense_analyzer
python expense_analyzer.py
```

### File Sorter

```bash
cd 02_file_sorter
python file_sorter.py
```

### Text Cleaner

```bash
cd 03_text_cleaner
python text_cleaner.py
```

### Folder Reporter

```bash
cd 04_folder_reporter
python folder_reporter.py
```

### Duplicate Finder

```bash
cd 05_duplicate_finder
python duplicate_finder.py
```

### Personal Task Tracker

```bash
cd 06_personal_task_tracker
python main.py
```

### Notes Database

```bash
cd 07_notes_database
python main.py
```

### Book Catalog

```bash
cd 08_book_catalog
python main.py
```
